# ADR-0002 阅读引擎与适配器

- 状态：已实施；生产性能、Windows 窗口与完整恶意 EPUB 样例仍待验收
- 日期：2026-11-19
- 关联：S02、S02-A1～A5、T-011、T-012、D-02

## 背景

EPUB/TXT 来源不可信，阅读定位须跨排版与窗口变化保持稳定；阅读 UI 不应加载书籍 HTML、脚本或资源。阶段 2 需定义滚动和分页共同使用的章节与内容位置接口，并持久化每本书的排版选择。

## 决策

1. 主进程以纯文本章节块作为唯一渲染输入。TXT 保留章节、段落和已识别编码；EPUB 使用 ZIP 结构上限、严格 XML 解析和 spine 次序映射出文本块；不向渲染进程传送 EPUB XHTML、文件路径或书内资源，也不创建可执行的书籍文档。
2. 阅读 API 通过窄 IPC 提供 `openBook`、`readChapter`、`saveReading`。主进程校验 bookId、chapterId、内容哈希、章节块范围与 UTF-16 偏移；读取前复核复制文件哈希，并限制书籍文件/ZIP 条目大小。资源不自动加载，解析得到的外部引用不执行或请求。
3. 进度按章节 ID、正文块索引和块内 UTF-16 偏移保存；每书使用独立不可变修订记录。阅读状态不依赖屏幕页码或排版；保存包含内容哈希与排版，旧内容哈希不匹配时拒绝读取/写入，保留已有记录。
4. D-02 由用户于 2026-11-19 确认为 v1 同时提供滚动和分页。两者共享上述进度位置；滚动定位到正文块字符位置，分页从同一正文生成页面，按可用视口大小、字号和行距重算。
5. 四项排版设置即时应用并持久化：字号、行距、页边距和字体。另保存滚动/分页模式与浅色、深色、护眼主题；字体栈使用系统回退，不下载字体。
6. 不新增大型阅读引擎。复用现有书籍导入依赖与主进程文本适配器，减少二进制包、资源协议与远程/脚本风险；解析用 strict XML parser，不使用 WebView。

## 取舍与限制

- 分页是基于目标视口与文本长度估算页面块的轻量实现，而非 EPUB 固定布局或成熟排版引擎；窗口和高 DPI 的精确分页体验仍需实机验收。
- 当前单进程内缓存最近一次解析内容，缓存随读取哈希失效；超大书的冷启动和内存占用须在生产构建中测量。导入和解析限制不等同于百万字性能通过。
- S02-A5 仍需覆盖真实固定恶意 EPUB：脚本、远程资源、越界资源和压缩异常，并用网络/文件访问观测确认零外部请求和越权读取。
- Windows 与性能验收遵循 D-08；本 ADR 及本地 Linux 自动测试不声称替代目标平台验收。
