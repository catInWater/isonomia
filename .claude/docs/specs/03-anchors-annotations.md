# S03 出处锚点、划线与批注

状态：草案。需求：FR-3.1～3.7、FR-5.1～5.6、G2/G3、NFR-7/21。依赖：S02 阅读适配器、S00 持久化；D-07 跨章选区范围。

## 共享模型

锚点至少包含：anchorId、bookId、内容版本/文件身份、章节标识与可读标题、格式相关位置范围、原文 exact、少量 prefix/suffix、创建时间、schemaVersion。位置适配 EPUB/TXT，但不以可见页码为依据。划线保存颜色与锚点；批注保存稳定 ID、所属划线、正文与创建/修改时间。摘录独立保存可选 domain 字段，v1 无领域 UI。

书名作者作为当前元数据和出处快照的关系须明确：失去原书后仍能显示导出出处。快照用于可读表示，不替代稳定 bookId。格式专属定位字段经 ADR 决定。

## 解析契约

输入锚点和当前书内容，输出状态、候选位置及原因：

1. 精确位置有效且原文一致：精确命中。
2. 位置失效或内容版本变化：以章节、exact、prefix/suffix 做片段回退。
3. 多个相同片段无法唯一判断：返回歧义，不任意选首个；定位失败保留片段并显示“位置丢失”。

回退匹配的文本归一化和阈值需要 ADR 与重复片段测试确定。解析不得静默覆写原锚点或删除用户内容。所有笔记、搜索、导出调用相同契约。

## 批注交互

选中文字可一键高亮或直接写批注；输入框在旁边且不遮挡选区，新增想法不超过 3 次操作。多色划线重启保留；支持编辑批注/颜色、删除并撤销。选中高亮打开批注，点击批注定位原文并短暂强调。保存中/失败反馈遵守 S00；撤销期和崩溃恢复不产生悬空引用。

P1：书内划线列表按章节/时间查看；跨页选区可创建有效范围；人类可读出处为“书名 · 作者 · 章节”；摘录 domain 数据位。跨章实现以 D-07 为准。P2：批注标签。颜色是否有固定语义不提前写入数据规则。

## 验收

- S03-A1：不同章节、重复句、中文标点/空白、跨页选区固定样例产生完整锚点，文本范围无截断。
- S03-A2：改变字号、行距、字体、窗口尺寸后，同一锚点指向同一原文；固定 20 条抽查至少 19 条成功，歧义不得算成功。
- S03-A3：修改/替换文件后唯一片段成功回退；重复候选、片段删除、原书缺失显示位置丢失，片段和批注仍能查看/导出。
- S03-A4：批注与高亮双向跳转正确；新建不离开阅读位置，操作数满足 G2；多色/修改重启保留。
- S03-A5：删除撤销恢复原内容、颜色和引用关系；持久化错误不显示假成功。
- S03-A6（P1）：列表排序/跳转与跨页选区正常；domain 空值可迁移，导出可读出处完整。

## 测试

匹配算法单测（重复和模糊结果重点）、格式适配器契约测试、排版矩阵 UI 测试、删除/撤销/持久化集成测试。固定样例锚点构成后续阶段共同回归集。
