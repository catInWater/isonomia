# S02 阅读器

状态：草案（实现中；D-02 阅读模式已确认双模式，D-08 性能/窗口基线待实机确认）。需求：FR-2.1～2.9、NFR-1～3/14/16～18。依赖：S01；D-08 性能/窗口基线。

## 行为契约

- 阅读会话以 bookId 打开书籍，在 D-02 用户确认的模式中呈现章节、正文和当前位置。当前滚动单模式仅为工程提案，不等于范围已确认；目录点击跳转，无目录 TXT 使用正文入口。打不开书时保留书架与用户内容访问能力。
- 进度保存为内容位置而非屏幕页码，退出/重启/字体变化后恢复误差不超过一页。保存失败可见，不声称已保存。图片适配器从旧 `[alt]` 占位文本升级为图片位置时迁移旧字符偏移，保存适配器版本，不能因占位长度变化拒绝打开或重置有效进度。
- 1.0.0 改版（2026-11-21 用户要求）：字号、行距、页边距即时生效且持久化；字体固定为英文 Times New Roman、中文宋体（SimSun），缺失时依次使用 Songti SC、Noto Serif CJK SC、serif，不再提供字体选择。保留旧字体枚举读取兼容，但展示遵循固定字体。顶部控制台为符号按钮单行，鼠标到顶部显示、离开隐藏；Tab 聚焦时可访问。目录由左侧边缘或 T 键唤出，可收起。正文与界面背景随主题保持一致，滚动仍可用但不展示滚动条。
- 内容层提供统一的跳转、当前位置、选区与渲染高亮能力，由 S03 实现稳定锚点；搜索/批注/引用不能另建互不兼容的定位路径。EPUB 正文图片仅解析 OPF manifest 中经格式签名、图像尺寸和总量上限校验的书内 PNG/JPEG/GIF/WebP 资源，以章节正文位置呈现；仅允许受限 `data:` 图片，不渲染书籍 HTML、不解析 SVG，也不读取远程/未列入 manifest 的资源。超限或无效图片以 alt 文本/占位显示，不能阻断正文。图片保留自然宽高比，并从受限的数值尺寸属性、内联样式及 manifest 授权样式表中读取 `width`/`height`/`display`；仅接受有界 px/em/rem/%，不执行书籍 CSS 或加载 CSS URL。`inline`/`inline1` 等字形类及明确行内规则按原书声明的行内尺寸显示，其他插图在分页模式独占一页，且不超过阅读区域。书内引用/脚注链接解析为章节与 UTF-16 内容位置，支持同章、跨章、片段编码和返回链接，在滚动/分页模式中使用右上标引用入口，点击后在引用处显示按内容自适应、受视口约束的纯文本气泡，不切章、不修改阅读位置；Escape、关闭按钮及点外部可关闭。目标段落中的图片显示安全占位，不执行目标中的链接或书籍 HTML。此契约不改变笔记出处显式回跳原文的行为；只开放当前 spine 中有确切目标的链接，外链、越界、未授权或目标缺失链接保留文字但不执行导航，不将原书 URL/路径交给渲染器。
- 导入内容是非可信数据：脚本禁用，资源只允许书内授权资源，不自动加载远程图片/字体，不允许路径越界。坏资源显示可读回退。阶段 0 壳层的请求白名单和 sandbox 仅是外层防线；EPUB/TXT 解析器仍须在 T-006/T-011 以恶意资源样例验证，不得将壳层测试视为阅读安全验收。
- 界面只展示用户自己的内容，无推荐或其他读者内容。翻页/滚动、目录和设置保留合理焦点；排版变化不打断编辑中的笔记。

P1：浅/深/护眼主题；专注模式保存并可恢复进入前布局；快捷键覆盖翻页、目录、搜索、批注，设置可查看，编辑器聚焦时不误触阅读快捷键。

P2：本机阅读时长统计，不采集遥测。

## 验收

- S02-A1：EPUB/TXT 正文和目录正确，首尾章、空章、长章可导航；D-02 确认的模式均可使用。
- S02-A2：移动到中间位置后关闭重开，误差不超过一页；改变字号和窗口尺寸后仍回到同段内容。
- S02-A3：字号、行距、页边距即时生效并重启保留；字体按 1.0.0 固定的中英文衬线栈展示且无字体选择器，缺失字体回退，正常阅读不中断。
- S02-A4：约 100 万字基线生产版 3 秒内打开；翻页/滚动测试记录响应测量，按 D-08 基线验收。
- S02-A5：包含脚本、远程资源和越界资源的固定书籍不执行脚本、不发外部请求、不读取未授权路径。
- S02-A6（P1）：三主题、专注模式、键盘与焦点行为正确；常见窗口和高分屏无正文/控件遮挡。
- S02-A7（1.0.0）：正文链接标记为右上标；点击打开对应纯文本引用气泡而不改变章节、正文滚动位置或笔记分栏状态。气泡随短/长目标适配并限制于视口；Escape/关闭/点外关闭。顶部单行控制台与目录边缘唤出/隐藏符合指针路径，固定字号族、隐藏滚动条、主题一致、正文与笔记无白边。
