## 共同行为契约

- ID 独立于展示名称、文件路径、可见页码。文件身份和书架条目身份分开，支持保留重复副本及移除文件后保留笔记。
- 读者内容和书籍文件分离；变更可迁移，迁移前备份。界面“已保存”意味着持久化成功，不以仅更新内存代替。
- 后台任务至少有排队/执行/成功/失败/取消状态；取消支持度写入相应功能规格。失败结果说明原因与下一步，不能留下假成功或不完整的可见实体。
- 所有跨功能定位复用同一出处锚点和解析结果：精确命中、片段回退命中、位置丢失。引用不得依赖屏幕页码或当前排版。
- 原文、用户内容、AI 内容具有可识别的内容来源；默认离线且无追踪。远端请求只在用户主动开启相应功能后发生。
- 破坏性操作确认或可撤销；可访问名称、焦点顺序与键盘操作属于功能验收。
- 技术选型写入 ADR，功能实现细节写入对应规格；本轮不预先锁定数据库、阅读引擎、编辑器、中文索引或转换库。

## 规格完成与实现完成

规格 ready：依赖决策已解决，输入/输出/异常/验收无未决阻塞，测试样例合法且固定。实现 done：规格链接、对应测试、Nx 检查结果、必要 ADR、运行说明与演示记录齐全。规格验收编号可在测试名和票据中引用。
