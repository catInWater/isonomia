# S06 转换与导出

状态：草案。需求 FR-7.1～7.8、FR-5.5、NFR-18/21。依赖 S00、S01、S03、S04。

## 行为契约

P1：EPUB 与 TXT 双向后台转换，显示进度，不阻塞阅读。EPUB 转 TXT 保留章节顺序和标题，输出 UTF-8；TXT 转 EPUB 复用编码与章节识别，支持书名、作者、封面。其他格式为 P2。

P0：转换产生新文件，不改变原书及批注；临时写入、校验后提交。失败有原因且无损坏半成品，取消清理临时文件，不静默覆盖目标。转换产物的身份及锚点关联由 ADR 决定，不直接复用旧格式位置。

P0：单书笔记导出为 UTF-8 Markdown，保留基础格式和带出处引用；出处至少为书名、作者、章节的可读组合（缺元数据时使用明确占位），不能只有应用内地址。P1：单书划线/批注按章节导出；全库笔记/批注以通用可读格式导出，含锚点及格式版本。原书缺失仍保留引用快照与失效状态。导出不等于 v1.5 完整备份恢复。

## 验收与测试

- S06-A1（P1）：转换章节和元数据正确，生成 EPUB 能重新导入阅读；固定样例往返测试。
- S06-A2：解析、写盘、校验时失败或取消，原文件及用户数据不变，无半成品；故障注入测试。
- S06-A3：不覆盖来源或静默覆盖目标，身份/锚点状态清楚。
- S06-A4：Markdown 可由通用编辑器打开，引用含书名、作者、章节和位置丢失状态；golden file 测试。
- S06-A5（P1）：批注导出全量且按章排序，原文、用户内容、出处可辨。
- S06-A6（P1）：全库笔记/批注导出有清单，数量及内容可与源数据核对；不是恢复功能承诺。
- S06-A7：断网正常工作；磁盘满、权限不足或目标占用时明确提示，原目标不受损。
