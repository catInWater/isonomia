# S01 书架与导入

状态：草案。需求：FR-1.1～1.10、FR-10.1～10.3、NFR-4/5/7/15。依赖：S00、D-05 文件所有权。

## 数据与边界

书架条目至少有稳定 bookId、文件身份/校验信息、格式、标题、作者、封面引用、导入时间、最近阅读时间、可选文件引用/分组/标签、文件可用状态。状态区分导入中、可阅读、文件缺失/已移除和失败。书名/作者修改不改变 bookId。原书是只读输入；用户内容单独存放。

## P0 行为

- 文件选择和拖放共享同一导入流程。验证 EPUB 容器/结构或 TXT 编码，后台提取元数据、正文与目录。每本书成功提交后才成为可阅读条目并产生索引任务；失败无残留可读假条目。
- T-000 D-05 确认前不实施导入文件生命周期。复制或引用均需将书籍文件作为不可信输入隔离；不得向渲染器暴露任意路径、协议、IPC 通道或文件系统能力，不得由导入内容发起网络请求；原路径文件始终为只读并不因书架操作而被改写/删除。具体隔离和所有权须在 T-001 ADR、T-006 样例测试中另行验证。
- EPUB 缺失封面/作者时提供占位，不因可选元数据缺失拒绝整本书；损坏核心结构则报告原因。
- TXT 支持 UTF-8（含 BOM）、GBK 等已声明常见编码。目录规则识别失败时按一个正文入口整本阅读，保留原始文件；编码不确定时提示而非静默乱码。手动规则调整能力按 PRD 风险项另行细化，不作为未声明的 P0。
- 书架支持封面/列表切换和书名、作者、最近阅读、导入时间排序。空书架有导入入口；恢复上次布局和排序。
- 删除确认明确区分“仅移除书文件，保留笔记”和“删除本书及用户内容”。保留内容仍可查看/导出，锚点标记原书不可用；引用外部文件时不得默认删除外部原件。导入复制/引用所有权、外部原件及清理行为尚待用户确认 D-05 和存储 ADR，不得将决定提案当作已确认契约。

## P1 与 P2

P1：批量/文件夹导入逐本进度，单本失败隔离；重复内容识别后选择跳过或保留两份（独立 bookId）；多标签/分组；设置显示并打开数据目录、主题/字号/字体默认值。重复检查按内容身份，不只看文件名。

P2：元数据/封面编辑、PDF 打开翻页、中文界面以外的多语言。PDF 划线能力降级必须可见。v1 首期界面使用中文，不必为此先实现多语言系统。

## 验收

- S01-A1：选择/拖入合法 EPUB，元数据与正文可用；无封面/作者样例正常显示占位。
- S01-A2：UTF-8、BOM、GBK 固定中文样例无乱码；无法识别章节仍能完整阅读；损坏文件/不支持格式失败原因清晰。
- S01-A3：两种布局及四种排序可切换，重启保留；500 本基线无明显阻塞。
- S01-A4：两种删除选择分别验证书文件/批注/笔记保留结果；取消确认不改变数据。保留笔记可导出；外部原文件不被误删。
- S01-A5（P1）：批量混合成功/失败，成功项继续完成；不同文件名同内容触发重复提示，保留两份互不覆盖。
- S01-A6（P1）：标签、分组持久化，单书可多标签；数据目录按钮打开正确目录，默认阅读设置传递到新打开书籍。

## 测试

解析/编码/去重/删除策略单测，临时数据目录集成测试，选择与拖放导入 UI 测试。注入导入中断、磁盘写入失败、原文件消失，确认不损坏现有条目。索引事件幂等，由 S05 消费。
