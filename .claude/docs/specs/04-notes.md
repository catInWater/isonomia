# S04 并排笔记

状态：阶段 4 P0/P1 核心实现及 Linux 验证已完成，Windows 实机与完整输入/辅助技术矩阵待验收；证据见[阶段 4 报告](../validation/04-notes.md)。范围已确认（2026-11-20）：一书一份笔记、基础五类格式；最后输入后 2 秒内开始保存，未确认输入在异常终止时不保证恢复；单次插入与等价拖放引用均纳入，跨章选择不纳入。需求：FR-4.1～4.8、G2/G5、NFR-6/7/14/16。依赖：S03 锚点、S00 保存恢复。

## 数据与行为

- 每个 bookId 关联一份稳定 noteId 的连续文档，打开书自动显示；不要求用户创建。D-06 已确认一书一份及排除图片/表格。空笔记可以延迟落盘，首次输入必须进入保存流程。内部文档、迁移及编辑事务见 [ADR-0004](../adr/0004-notes-editor.md)。
- 文档支持段落、标题、列表、引用、加粗，引用节点持有 anchorId、原文快照、可读出处；不能只存 HTML 链接或屏幕位置。内部文档格式和版本迁移经 ADR 选择。
- 1.0.0 改版（2026-11-21 用户要求）：正文左、笔记右，默认等宽；分隔条可键盘/鼠标调节、收起，调整后的比例持久化。左侧目录出现时，正文和笔记按原比例分享剩余空间。旧像素宽度设置在首次读取时使用默认等宽；已存比例设置继续恢复。调整布局不改变逻辑阅读位置或卸载编辑器；窄于 700 CSS px 使用笔记抽屉，避免两列无法编辑。格式按钮使用符号、保留中文无障碍名称，支持格式应用/取消及清除格式，撤销重做仍由同一编辑历史管理。
- 自动保存状态为待保存/保存中/已保存/失败；编辑时持续保存，异常退出恢复满足 D-03。并发保存防止旧请求覆盖新修订；写失败保留内存输入并提供重试/导出逃生路径。T-004 的 DurableStore 已验证已确认修订的原子发布、乱序/磁盘错误/迁移中断与强制终止；编辑器仍须实现并验证输入保存时序，不能将存储单测当作笔记验收。
- 一键把当前选区插入当前笔记光标位置；无光标时追加到文末。将选区拖放到笔记视为同等引用操作；笔记收起时，将本窗口正文选区拖至右侧空白投放区自动打开笔记并插入。外部 HTML/伪造 token 不可作为书内来源。插入为一个可撤销操作，出处引用持久化后可点击回原文。位置丢失显示快照片段及状态，不阻塞继续写作。
- v1 原文快照不随笔记编辑或书文件替换隐式变化；用户文字和引用来源在视觉上可区分。移除书文件后仍可打开/编辑/导出保留笔记。

P1：单条批注/全部批注按章节、块、偏移顺序汇入笔记，统一追加文末，保留已有用户文字。只汇入有批注的条目；同一 annotationId 已汇入则跳过，即使原批注后来修改也不隐式刷新副本；撤销汇入同时撤销去重标记。窄窗口笔记抽屉不丢光标/正文位置。此为本次工程默认规则，不扩展为批注同步/更新能力。拖放引用已纳入阶段 4 P0（D-07），不属于批注汇入票据。P2：笔记标题大纲。表格、图片、多笔记不在当前承诺。

## 验收

- S04-A1：打开两本书分别编辑，再切回/重启，各自笔记正确且一书一份。
- S04-A2：五类基础格式往返保存无内容丢失；输入不需要保存按钮；保存失败可见并可恢复。
- S04-A3：模拟写入乱序、强制终止和恢复，最新已确认修订不被覆盖；输入损失符合确认的时限。
- S04-A4：选区一键插入、撤销/重做、点击回原文成功；改字号后依旧定位；原书缺失保留引用与笔记。
- S04-A5：分栏拖动/收起并重启恢复；键盘可操作，阅读位置不变。窄窗抽屉按 P1 验收。
- S04-A6（P1）：批注汇入顺序与去重策略可预测，已有用户文字不被覆盖；拖放引用按 D-07 决策验收。
- S04-A7（1.0.0）：默认等宽双栏；目录出现时按比例共享剩余宽度；分隔条拖动/键盘修改比例且重启恢复。笔记收起时拖选区至右侧空白目标自动展开并插入单一可撤销来源。全部基础样式均可应用/取消，清除格式工作，工具栏图标有可访问标签。
