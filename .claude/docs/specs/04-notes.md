# S04 并排笔记

状态：草案。需求：FR-4.1～4.8、G2/G5、NFR-6/7/14/16。依赖：S03 锚点、S00 保存恢复；D-03 保存时限、D-06 笔记范围、D-07 拖放优先级。

## 数据与行为

- 每个 bookId 关联一份稳定 noteId 的连续文档，打开书自动显示；不要求用户创建。空笔记可以延迟落盘，首次输入必须进入保存流程。
- 文档支持段落、标题、列表、引用、加粗，引用节点持有 anchorId、原文快照、可读出处；不能只存 HTML 链接或屏幕位置。内部文档格式和版本迁移经 ADR 选择。
- 正文左、笔记右，分隔条可键盘/鼠标调节、收起，布局持久化；调整布局不改变阅读位置或编辑选区。
- 自动保存状态为待保存/保存中/已保存/失败；编辑时持续保存，异常退出恢复满足 D-03。并发保存防止旧请求覆盖新修订；写失败保留内存输入并提供重试/导出逃生路径。
- 一键把当前选区插入当前笔记光标位置；无光标时追加到文末。插入为一个可撤销操作，出处引用持久化后可点击回原文。位置丢失显示快照片段及状态，不阻塞继续写作。
- v1 原文快照不随笔记编辑或书文件替换隐式变化；用户文字和引用来源在视觉上可区分。移除书文件后仍可打开/编辑/导出保留笔记。

P1：单条批注/全部批注按章节汇入笔记，重复执行的去重策略和插入边界需明确（草案建议只跳过已关联同一批注 ID 的插入）；窄窗口笔记抽屉，不丢光标/正文位置。P2：笔记标题大纲。表格、图片、多笔记不在当前承诺。

## 验收

- S04-A1：打开两本书分别编辑，再切回/重启，各自笔记正确且一书一份。
- S04-A2：五类基础格式往返保存无内容丢失；输入不需要保存按钮；保存失败可见并可恢复。
- S04-A3：模拟写入乱序、强制终止和恢复，最新已确认修订不被覆盖；输入损失符合确认的时限。
- S04-A4：选区一键插入、撤销/重做、点击回原文成功；改字号后依旧定位；原书缺失保留引用与笔记。
- S04-A5：分栏拖动/收起并重启恢复；键盘可操作，阅读位置不变。窄窗抽屉按 P1 验收。
- S04-A6（P1）：批注汇入顺序与去重策略可预测，已有用户文字不被覆盖；拖放引用按 D-07 决策验收。
