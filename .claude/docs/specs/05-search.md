# S05 搜索

状态：草案。需求：FR-6.1～6.9、NFR-4/21、G4。依赖：S01 内容提取、S03 锚点解析、S04 笔记修订。

## 输入输出

查询包括文本、范围和可选内容类型；空查询不进行全库扫描。结果包含稳定 resultId、bookId、来源类型（原文/批注/笔记）、章节、带命中范围的上下文、可用定位引用。书内和全库使用同一查询语义；全库结果按书分组，来源类型可见。

笔记中自由写作的命中跳到对应笔记节点；带出处引用命中可继续跳原文，不能凭空为用户自由文字制造原文锚点。

## 索引与查询契约

- 中文单字/双字词可检索，不要求整句。先对中文分词、子串或其他候选方案用固定数据评测，再 ADR 选型；不以默认英文分词索引直接验收。
- 索引是可重建派生数据，原书与用户内容为事实来源。导入、批注/笔记修改和删除产生幂等更新，更新按内容版本提交，旧任务不覆盖新版本。
- 后台索引不阻塞阅读；状态显示待索引/进行中/完成/失败，失败可重试。文件删除保留笔记时，保留内容仍可被搜索，原文可用性如实显示。
- 中断后继续/重建不出现重复结果；查询切换时旧响应不得覆盖新查询。错误可恢复，索引损坏不损坏源数据。
- P0 提供当前书、全库和自己的内容搜索；P1 增加分组范围、仅用户内容筛选、命中高亮与相关度排序（P0 仍需显示命中上下文，并在点击后定位强调）。P2 语义搜索不在字面索引实现中预埋远端调用。

## 验收

- S05-A1：单字“孤”、双字“孤独”和跨标点/重复词固定样例返回预期结果；无结果/空输入有明确反馈。
- S05-A2：全库按书分组，原文/笔记/批注可区分；点击分别跳原文锚点或笔记位置，失效状态保留片段。
- S05-A3：约定的 100 本固定测试规模下，从输入结束到结果可见不超过 1 秒；记录冷/热索引、总字数、硬件和统计口径，不能只测查询函数。
- S05-A4：导入后后台索引完成可检索；“合理时间”在数据集基线确认后给定具体阈值；索引期间正常翻页和编辑。
- S05-A5：编辑、删除、快速连续查询与索引中断不产生陈旧覆盖/重复；重建后与源数据一致。
- S05-A6（P1）：过滤组合、命中高亮与相关度固定用例符合预期。
